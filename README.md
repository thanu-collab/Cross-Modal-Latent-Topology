# AI Cross-Modal Latent Geometric Topological Mapper for Generative Manifolds

An advanced engineering project exploring cross-modal latent spaces using topological data analysis and geometric mapping techniques.

## Overview
This repository contains the core implementation notebook (`CrossModal_TDA_Mapper.ipynb`), leveraging topological data analysis (TDA) and deep learning models to map and analyze generative manifolds.

## Tech Stack & Libraries
* **Python**
* **PyTorch / Hugging Face Transformers**
* **SciPy / NumPy**
* **Ripser** (for topological data analysis)

## Usage
Open `CrossModal_TDA_Mapper.ipynb` in Google Colab or your local Jupyter environment to run the pipeline, generate embeddings, and visualize the topological structures.
